## Overview

UE4SS (Unreal Engine Script System) is an open-source modding framework for games built on Unreal Engine 4 and 5, providing a Lua scripting API with full access to the UObject hierarchy, a Blueprint class dumper for modding reference, an in-game debug console for live property editing, and a mod loader used by hundreds of community mods across RE Engine-adjacent UE titles. It has become the essential foundation for mod development in UE-based games.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **UE4SS** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Lua Scripting** | Write mods in Lua with access to the complete UObject and UClass hierarchy |
| **Blueprint Dumper** | Dump UClass hierarchies and property names for accurate modding reference |
| **Live Debug Console** | Read and write UObject properties in-game via the integrated console |
| **UE4 and UE5 Support** | Single framework compatible with both Unreal Engine 4 and 5 games |
